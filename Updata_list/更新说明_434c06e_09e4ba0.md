## 本次更新概览

新增剪贴板文件定位快捷键，完善首页公告刷新，优化中控视频切换，并加强更新安装的启动确认与失败恢复。

本说明覆盖提交范围：`434c06e11cf273394e5d1aae242cc48fa5c45a3e` → `09e4ba0d5fdcc4222dcdddc010f41ba47abce038`（不包含起始提交，包含结束提交）。包含该范围内已发布的 v101 跨位数更新修复；已安装 v101 的用户已具备这项修复。

## 新增：剪贴板定位文件

- 默认快捷键 **Shift+F1**。复制文件名，点击受支持的文件列表后触发，即可模拟连续输入名称，利用列表原有的键入定位能力查找文件。
- 支持 Kedit 的三个文件树（`SysTreeView321`、`SysTreeView322`、`SysTreeView323`），以及 Windows 资源管理器的文件列表。
- 根据键盘焦点判断作用区域，避免向代码编辑区、地址栏、搜索框或重命名输入框发送文字；发送过程中再次核对目标。
- 只接受单行文本，去除首尾空格和 Tab；拒绝空内容、多行／控制字符、超过 260 个字符的文本，以及复制的文件对象。
- 保留剪贴板原内容，不发送 Enter，不自动打开文件。匹配结果遵循目标列表自身的规则。
- 加入同风格的托盘菜单和中控 Kedit 配置页，可修改快捷键；触发计入本地使用统计。

## 首页公告刷新优化

- 保留启动时的后台检查，新增每 **20 分钟**自动检查公告；中控隐藏时仍会检查。
- 管理员按钮右侧的预留按钮改为 **刷新公告**，普通用户也可手动刷新。
- 按钮悬停提示展示最近检查结果；已有刷新请求时不重复发起。
- 网络失败保留本地公告；内容没有变化时，不重建栏目或重置轮播。
- 内容变化时尽量按原栏目、轮播项标识保留当前位置；退出中控后停止定时检查。

## 中控视频背景与过渡优化

- 不同视频使用双播放器交替加载，旧视频在新视频准备期间继续播放；切换结束后关闭旧视频，控制播放器数量。
- 相同视频继续播放，只调整当前页面构图，不因切页重新加载。
- 标题和设置面板即时切换，背景准备在后台进行。
- 优化首帧衔接、连续快速切页和过渡状态管理，减少黑屏、突变及中途亮度下沉。
- 加载失败或超时显示独立提示；有可恢复的旧背景时保留或恢复旧背景。
- 默认采用 **快速柔切（180ms）**，以短促、柔和的叠化切换背景。

管理员区新增“过渡风格预览”，可选择以下七种方式进行比较；选择仅本次运行生效，不修改页面素材配置：

| 风格 | 特点 |
| --- | --- |
| 纯叠化 | 450ms，柔和显现新画面 |
| 轻微失焦叠化 | 450ms，轻度模糊后恢复清晰 |
| 景深换焦 | 600ms，较明显的失焦与清晰交接 |
| 柔边横向揭幕 | 550ms，新画面由右向左揭开，边界柔和 |
| 快速柔切（默认） | 180ms，短促利落 |
| 快入缓收 | 220ms，快速显现、缓慢收尾 |
| 就绪即切 | 新视频就绪后直接替换，不增加过渡动画 |

## 更新安装修复与启动保护

- 修复 **“32 位进程无法访问 64 位进程的模块”** 导致安装准备失败的问题。获取主程序路径改用跨位数适用的进程路径查询接口，不再通过模块枚举获取路径。
- 安装前增加独立更新器就绪确认；更新器未能确认启动时，保留正在运行的旧程序。
- 替换后，新版通过本次启动专用的一次性标识报告核心初始化成功：配置与快捷键初始化完成，主程序消息循环能够响应。公告、视频和 NAS 网络加载不作为启动验收条件。
- 新版须在 **30 秒**内报告就绪，随后继续观察 **5 秒**。启动确认超时、提前退出或观察期退出时，尝试停止本次新版进程、恢复旧 EXE 并启动旧版，提示失败原因。
- 回滚只处理程序文件，不覆盖用户配置。启动验收成功后清理旧 EXE 备份；清理失败不会因此回滚已正常启动的新版。
- 扩展跨位数安装准备、更新器就绪握手、AHK 启动确认、启动失败恢复及发布准备工具的回归测试。

### 升级须知

- 如果旧版本更新时仍出现上述跨位数报错，请手动下载本次正式发行的完整 EXE 完成一次替换；该旧版的安装错误无法仅靠服务端发布新包修复。
- 新增启动回滚保护由发起更新的程序提供。**首次升级到本版本时仍使用旧版本自带的更新器；本版本安装成功后，由它发起的后续升级才具备这套新保护。**
- 该机制检查启动阶段，不代表对长期运行故障提供自动回滚保证。
