# 页面视频与 GIF

管理员在当前页面选择 GIF / MP4 后，记录会写入本目录的 pages.json。

- 项目内运行中控时读取项目配置；离开项目运行的 EXE 读取构建时嵌入的配置与素材。
- 文件名以相对路径保存。目录外素材复制到本目录，附加内容哈希，避免覆盖同名文件。
- 首页、每个快捷键、每个桌宠子页分别保存。恢复默认只移除该页映射，不删除素材。
- 重新构建 Kedit.Console 后，引用素材自动嵌入；未引用素材不嵌入，共用文件只嵌入一次。
- 文件缺失、路径不合法、GIF 无法解码、MP4 容器缺失或截断会阻止构建并标出页面。MP4 容器校验不等同逐帧解码，编码兼容性仍需播放验收。
- 不要手动将绝对路径写进 pages.json。生成 EXE 后才更改的映射需重新构建方能生效。
- 管理员“页面素材清单”显示已配置和未配置页面。

页面标识：home；kedit.<INI键名>；vs.<INI键名>；pet.display / follow / typing / props / care / music / schedule / osd；updates；other。

## 管理员调试目录
解锁管理员后点击“素材项目目录”，选择包含 Kedit.Console 的项目根目录。本机会记忆此目录，下次解锁恢复。逐页选择 GIF / MP4 后自动预览并保存到 mp4/pages.json，无需点击快捷键的保存按钮。下一次构建才进入新 EXE。管理员区显示项目、当前素材及清单路径。独立 EXE 普通启动仍使用内置素材。
