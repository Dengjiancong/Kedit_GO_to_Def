# 列编辑发布验收

日期：2026-10-16

## 已完成

- 用户已实测确认：原选区不再上移，横向滚动后列选择不再跳动。
- 自动回归：矩形插入/替换、连续输入、退格、撤销/重做、Tab 内部分割、短行补空格、空白行处理、换行保留、写回文件。
- 自动回归：横向滚动后开始选择、输入、撤销、重做保持滚动位置。
- 新增回归：矩形复制按原行 Tab 位置展开；短行复制补齐；替换相同文字后继续输入。
- 修复：编辑结果为空时，AHK 删除原选区，而非粘贴空剪贴板。
- 修复：焦点不在编辑框时，不执行列编辑快捷键。
- Release 构建通过（仍有既有 ToolsVersion 工具集回退提示）。

## 本轮补充验收

- 方向键整体移动、Shift 固定起点扩展/缩小、跨起点反向选择、边界停止：回归通过。
- 长行左右滚动跟随、移动后继续多行写入：回归通过。
- Esc 的 PreviewKeyDown 事件被列模式拦截；窗口仍打开，文字和滚动位置保留：通过。
- 关闭后重开恢复宽高；NaN/Infinity 等损坏尺寸回退默认值：通过。
- 双击完整名称的范围计算（字母、数字、下划线）：通过。
- 没有发现新的发布阻断问题；以下最终包实测仍未由自动测试覆盖。

## 发布包最后实测

以下尚不能以控件测试代替真实 Kedit/打包 EXE 验收：

- 使用最终打包 EXE：打开、取消，再次 Alt+I；确认退出后无编辑器残留。
- 选中多行并完整删除，确认后只删除原选区；Kedit 撤销能恢复。
- 打开列编辑后修改 Kedit 原选区，确认写回应被拒绝。
- 中文输入法组合输入、多显示器不同缩放下的鼠标列定位。
- 普通模式 Esc 实际关闭；列模式第一次 Esc 只取消列选择，第二次关闭。
- 最终包在主/副屏打开居中、尺寸不越界；调整大小后重新打开恢复。
- 在整份文本最长行以外的虚拟列继续右移：原生文本框的滚动范围有限，尚未提供无限虚拟画布，不保证光标始终可见。

## 当前范围

- 矩形粘贴支持单行重复填入；多行剪贴板在列模式下会提示，不会修改文本。普通编辑支持多行粘贴。
- Tab 列计算固定为 4；不是完整的 Notepad++ 功能实现。
- 中文宽字符、组合字符与 emoji 的列宽/删除语义尚未完整验证，不应宣称任意 Unicode 文本列编辑兼容。
- 保留实际选区，首尾部分行不会自动扩成完整行。
- 写回通过窗口与选中文本一致性检查；不能识别“同一窗口内其他位置的完全相同文本”。
