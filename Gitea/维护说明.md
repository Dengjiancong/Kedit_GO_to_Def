# 上传与维护说明

## 一、首次上传

1. 在 Gitea 打开 EVADD/Kedit_Content，确保仓库允许匿名读取。
2. 如仓库为空，先初始化默认分支（建议 main）；已有仓库沿用现有分支即可。
3. 上传本目录内四个文件到仓库根目录并提交。
4. 分别打开 home.json 和 models.json，点击“原始内容 / Raw”，复制实际地址，提供给中控接入使用。
5. 用未登录的浏览器窗口打开原始地址，应直接看到 JSON 文本，而不是登录页或仓库 HTML 页面。

若分支确实为 main，常见原始地址形如：
https://gitea.evadd.xyz:88/EVADD/Kedit_Content/raw/branch/main/home.json
https://gitea.evadd.xyz:88/EVADD/Kedit_Content/raw/branch/main/models.json

以上为待验证示例，不表示已确认远程仓库分支或访问状态。不要把 Gitea 登录密码或访问令牌写进清单或客户端。

## 二、改图片、链接与公告

home.json 的 carousel.items 按数组顺序轮播，image_url 为图片直链，target_url 为点击后打开的网页。title 为显示标题；id 保持稳定，不随标题改动。
interval_seconds 为轮播秒数，direction=left_to_right 表示向右滑动，pause_on_hover=true 表示悬停暂停。
公告、新闻、资讯在 tabs 下，各自的 items 内添加标题、日期和跳转地址。日期采用 YYYY-MM-DD。没有内容时保留空数组 []，客户端显示暂无内容。

修改时使用 Gitea 网页编辑器；保留英文双引号和 JSON 标点，不写注释或末尾多余逗号。每次发布将 revision 加 1，updated_at 更新为实际修改日期。schema_version 暂保持 1。
上传新图片建议使用新文件名，避免旧缓存。图片无需 base64 写入 JSON，也无需上传本仓库。

## 三、准备兔兔模型

默认模型 id=amiya-bunny，版本 1.0。保留作者署名、作者主页、原下载入口及原包许可说明；清单不另行授予模型许可。

字段含义：
- share_url：用浏览器打开的 NAS 分享页面。
- download_url：返回模型压缩包文件的免登录 HTTPS 直链，已匿名验证可下载 ZIP。
- sha256：整个下载压缩包的 SHA-256，已下载核验，与用户提供值一致。
- size_display：用户提供的约略大小，仅供显示。
- size_bytes：实际文件字节数，当前已核验为 8168653 字节；以后更换包时重新测量。
- archive_format：实际压缩格式；建议准备 zip。当前已核验为 zip。
- model_entry：压缩包内 .model3.json 的相对路径，使用 / 分隔；未知时为 null，后续客户端可在解压后发现唯一入口，多入口时应让用户选择。
- original_download_page：作者原下载网页，作为手动备用入口，不作为自动下载直链。

永久分享不等于文件直链。需确认文件下载无需登录、密码、验证码或 Cookie，且不会返回 HTML。拿到实际包后核对校验值、格式、字节数和模型入口。不要将名称改为 zip 来冒充 ZIP 文件。
PowerShell 核验示例（将路径替换为实际模型包）：

```powershell
Get-FileHash -LiteralPath 'D:\模型包.zip' -Algorithm SHA256
(Get-Item -LiteralPath 'D:\模型包.zip').Length
```

下载、校验、解压、自动选择由后续客户端完成；若未来 download_url=null，应提供“打开分享页”和“作者原下载页”，不能尝试解压分享网页。
模型更新后同时更新版本、下载地址、大小与校验值，避免旧地址对应新哈希。

## 四、客户端接入约定（待实现）

- 首页先显示最近有效缓存；首次无缓存时显示软件内置内容。
- 后台请求清单；网络或格式错误不覆盖有效缓存，保留原有展示。
- 新图片下载失败继续使用缓存或内置图片，不让轮播区域空白。
- 公告与模型清单分别校验，一份失败不阻塞另一份。
- 点击链接使用默认浏览器，仅接受网页 HTTP/HTTPS 地址，不执行清单中的命令。
- 自动下载模型时校验 SHA-256，拒绝校验失败的包；解压限制在模型目录内，避免覆盖已有自选模型。
- 清单与图片缓存不承担模型下载成功的保证；NAS 不可用时说明原因并保留手动原下载入口。
- 异地备用内容源以后再做，本轮不配置。

本清单结构为当前约定，后续开发必须按这些字段接入或同步升级模板，不能仅凭上传判定功能已上线。

当前包内中文文件名存在旧式 ZIP 编码，客户端实现时需兼容，并自动发现唯一 .model3.json；model_entry 留 null 是有意设置。
